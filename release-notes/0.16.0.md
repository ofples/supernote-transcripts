# Supernote Transcripts 0.16.0

This prerelease consolidates plugin support files under `_supernote/` and adds safer update controls, storage migration, and Reader integration. Transcripts remains usable without the optional Reader, Paper theme, Sidebar companion, or Bridge app.

## Storage and updates

- Move history, archive, shared data, and glossaries into `_supernote/`; preflight legacy moves, stop on content conflicts, and support safe retry after interruption.
- Keep transcript output in its configured folder and exclude plugin support files from Obsidian Search and Quick Switcher.
- Add automatic check modes and per-source overrides, one-shot notebook checks, queue controls, and check timestamps.
- Adopt exact current shared recognition results during automatic discovery while honoring exclusions, forced retries, and the edit-conflict guard.
- Reuse bounded page indexes for reading and OCR, and preserve manual Markdown edits through explicit reconciliation.

## Reader integration

- Add persistent Reader Highlights and safer quote relocation using unique quote text and saved context.
- Validate managed transcript provenance before Reader selections use notebook and page details.
- Support source-specific native Digest category preferences through the optional Reader adapter.

The optional Android Reader and Bridge workflow has separate releases. See [installation](../docs/installation.md), [component boundaries](../INTEGRATION.md), and [validation notes](../VALIDATION.md) for requirements and verification limits. Native Digest backlinks into `.note` files remain unsupported; the workflow leaves source notebooks untouched.

Automated verification passed on the release source: 658/658 tests, TypeScript checking, and production build. The manual-install ZIP contains only `main.js`, `manifest.json`, `styles.css`, `LICENSE`, and `NOTICE.md`; its SHA-256 and the standalone file hashes are attached as `SHA256SUMS`. Device activation and physical acceptance are tracked separately in [Validation](../VALIDATION.md).
