# 0.15.0

This release adds the optional Android Reader-to-Digest handoff and the Transcripts selection-provenance adapter used by MD Reader 2.1.3.

## Native Digests

- Select text in MD Reader on Android and choose **Save to Supernote Digest**.
- Review the excerpt and source in Supernote Bridge, then confirm **Save Digest**. The Bridge UI confirms creation before Reader reports acknowledgement.
- Managed transcripts require a matching local notebook mirror and verified page identities. Source provenance is retained when page chips are hidden.
- Ordinary Markdown selections retain their vault path and nearby context and do not require the Transcripts plugin.
- Bridge 0.4.0 is a separate optional Android app. Download `Supernote-Bridge-0.4.0.apk` from this release; source build instructions are also available.

Bridge creates and reads back a native Manual Entry through the permissioned provider. It does not make AI requests or directly edit native notebook files. It supplies Markdown or notebook/page provenance and provides an **Open original notebook** action after save. Native Notes' Digest source action requires an embedded reference in the `.note` file; Transcripts and Bridge do not write that reference, so native Digest-to-notebook navigation is unsupported. Exact ink-coordinate mapping is also unavailable.

Controlled creation, readback, and native visibility of a synthetic Digest were verified. Reader-to-Bridge confirmation and Cancel passed on Nomad for ordinary Markdown and a managed transcript. The complete production Save/acknowledgement/Open-original sequence has not been exercised live. Cloud sync, Partner behavior, rename behavior, and cross-device resolution remain unverified.

For installation, protocol details, and current limits, see [Native Digests](../docs/native-digests.md). This feature is independent of ordinary transcription and the existing page-link chip workflow.
