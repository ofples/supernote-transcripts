# Supernote Transcripts 0.17.0

This prerelease streamlines the existing Supernote-to-Markdown workflow in Obsidian.

- Use **Add source** to save a notebook or folder for recurring updates. Use **Transcribe file or folder** for a one-time run. Both commands use the same file browser.
- Follow progress and open actionable issues from the desktop status bar. Queue shows active, waiting, paused, and completed work.
- Configure connection, recognition, updates, and storage in Obsidian Settings. Save reusable recognition and cleanup prompts as revisions. Apply optional settings to an individual run.
- Configure a source, clean up a transcript, or re-recognize selected pages with consistent controls and a visible action area.
- Insert protected manual sections in managed transcripts and use the existing recovery tools to review conflicting edits.

## Upgrade

Download the manual-install ZIP and replace `main.js`, `manifest.json`, and `styles.css` in the existing plugin folder. Keep the saved settings, state, and transcripts. See the [installation guide](../docs/installation.md) and [user guide](../docs/user-guide.md).

## Verification

The release was tested with synthetic notebooks and a local test provider. The visual review used desktop Obsidian in dark and light mode, with additional compact-layout fixtures. Physical Nomad acceptance remains separate.
